Privacy Policy

Last updated: July 2026

Fiverr Doctor ("the Extension") respects your privacy. This policy describes what information the Extension collects and how it is used.

Data Collected

  • Fiverr username — extracted from the page header to generate a personalized notification topic.
  • ntfy topic — a random or user-defined identifier used to route push notifications.
  • Balance information — your visible Fiverr balance, stored locally for display in the popup.
  • Extension preferences — toggle states (dark mode, hide balance, etc.) stored in your browser.
  • Session activity — active/idle time on Fiverr, stored locally and never transmitted.

How Data Is Used

  • All preference data is stored in chrome.storage.local and never leaves your browser.
  • The ntfy topic is sent to ntfy.sh only when delivering a push notification. No other personal data is included in the request.
  • Balance and session data are used solely for display within the Extension popup.

Third-Party Services

The Extension uses ntfy.sh to deliver push notifications to your phone. When a new message is detected, a request containing your topic identifier and a generic message ("You have received a new message on Fiverr") is sent to ntfy.sh. No personal information, Fiverr credentials, or message content is transmitted.

ntfy.sh is an open-source notification service. Refer to their privacy policy for details on how they handle data.

Data Storage

All extension data is stored locally in your browser using the chrome.storage.local API. No data is sent to any server except the ntfy.sh push notification request described above.

Data Sharing

We do not sell, trade, or share your personal data with any third parties. The only external request is the ntfy.sh notification delivery, which contains only the topic identifier and a fixed notification message.

Contact

If you have questions about this privacy policy, please open an issue on the extension's support page.
